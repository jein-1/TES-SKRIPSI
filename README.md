## 🛡️ TENTANG SISTEM A.T.L.A.S
A.T.L.A.S adalah ekosistem pertahanan dan telemetri keselamatan kebencanaan *real-time* yang dirancang untuk memetakan ancaman gempabumi tektonik dan tsunami secara presisi di kawasan pesisir Teluk Palu, Sulawesi Tengah. Sistem ini mengintegrasikan data telemetri BMKG, pemodelan Zona Rawan Bencana (ZRB), navigasi evakuasi mandiri berstandar militer/taktis A.T.L.A.S, dan pelacakan unit keluarga *sharelock-grade*.
